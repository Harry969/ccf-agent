# Workflow  The default workflow is:  1. Fill a JSON config with the target paper, model profile, LaTeX template, chapter skill, style skill, and few-shot file. 2. Build a context brief from local Markdown notes when a paper corpus is available. 3. Run `ccf-agent render` to create a model-ready prompt bundle. 4. Send the prompt bundle to the chosen model/API. 5. Place the generated LaTeX into the paper scaffold. 6. Run `ccf-agent evaluate` on the result. 7. Generate a judge pack with `ccf-agent judge-pack`. 8. Use `prompts/logic-judge.md` for sentence, pseudocode, and equation review. 9. Use `prompts/review.md` to revise sections that fail checks or feel technically weak.  ## Model/API Integration  This repository does not ship API credentials or a mandatory provider adapter. That is deliberate. Many users will run the prompt bundle through Claude, OpenAI, local models, IDE agents, or custom harnesses.  Recommended orchestration contract:  - Read `build/prompt.md`. - Optional: read `build/context-brief.md`. - Send it to the selected model with the configured reasoning/thinking profile. - Save the model output to `paper/sections/<section>.tex`. - Use `templates/latex/method-chapter.tex` as the generic method-section starting point when drafting a new algorithm chapter. - Run the harness. - Generate `build/review-pack.md` and run the logic judge. - Keep model output, harness result, and human edits in version control.  ## Advanced Review  For sections with equations or pseudocode, run the advanced harness after the coarse check:  - sentence judge for the first paragraph of each technical subsection, - pseudocode-line judge for every algorithm block, - equation form judge for each displayed equation and its declaration window.  This mirrors the `kv` reference workflow where the draft is judged at the level of local logical load, not only at the level of section presence.  ## Human Review  The harness checks for structure. A human author still owns:  - correctness of the theorem or algorithm, - appropriateness of claims for the target venue, - citation quality, - experiment validity, - final voice and taste.
