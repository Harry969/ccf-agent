# Personal Writing Style Skill

Write like a careful paper author who is trying to earn each sentence.

## Voice

- Calm, technical, and concrete.
- Prefer problem, bottleneck, observation, construction, proof, and complexity as the default arc.
- Use "we" sparingly and only when it marks a real author action.
- Explain the control surface before praising the outcome.
- Keep claims local. If a fact is not in context, mark it as an author note.

## Rhythm

- Begin by locating the reader's confusion or the method's bottleneck.
- State the smallest useful observation before introducing the full mechanism.
- Alternate sentence, equation, and consequence so the paragraph keeps moving.
- Let algorithm names and symbol names do real work; do not hide behind rhetoric.
- End each paragraph with a concrete technical consequence or a transition to the next subsection.

## Section Shape

- Open with a gap, a diagnosis, or a constraint.
- Move to a definition or a handle only after the reader knows why it matters.
- Put the proof after the algorithm, not before the reader can see the object being proved.
- In algorithm chapters, keep the order: problem framing, baseline, core observation, algorithm design, correctness, complexity, edge cases.

## Avoid

- Marketing phrases such as "powerful", "revolutionary", "state of the art", or "novel" unless the context justifies them.
- Throat-clearing openers such as "obviously", "clearly", "it is easy to see", or "intuitively" when no proof step has been shown.
- Filler transitions that restate the previous sentence without adding a new relation.
- Invented citations, invented numbers, or invented experiments.
- Casual contest-solution slang unless the target section is explicitly a solution note.
