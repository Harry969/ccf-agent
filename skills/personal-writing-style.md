# Personal Writing Style Skill

这个 skill 用来保存作者自己的算法章节写作风格。当前是初始模板，后续应该用真实文章迭代。

## 语气

- 清楚、冷静、有判断。
- 不故作神秘，不堆砌术语。
- 允许有少量个人化表达，但不抢正文。

## 结构偏好

- 先给读者一个可抓住的问题图景。
- 再指出朴素做法卡在哪里。
- 核心观察要单独成段，语气要坚定。
- 解释实现时优先讲不变量、边界和变量含义。

## 避免

- “显然”“容易发现”等跳步表达。
- 只有代码没有解释。
- 正确性说明只复述算法流程。
- 太像标准答案模板的机械小标题。

## 常用表达方式

- “这个问题的关键不在于枚举更多情况，而在于找到一个能被维护的量。”
- “从这个角度看，状态的含义就比转移本身更重要。”
- “实现时真正容易出错的是边界，而不是主循环。”
